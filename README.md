# Поиск клиентов без сайта → Telegram

Находит местный бизнес, у которого нет сайта, и раз в день присылает список
в Telegram: название, категория, телефон, адрес, ссылки на карту.

Зачем: биржи фриланса платные или требуют статус, а клиенты — рядом. Такой список
не заменяет холодные сообщения, но даёт с чего начать: 10 контактов в день,
которым реально можно предложить сайт.

## Что внутри

```
parser/
├── main.py                     # дайджест, отправка, защита от повторов
├── config.py                   # город, категории, токены (.env / os.getenv)
├── .env                        # локальные токены, в git не попадает
├── requirements.txt            # только requests
├── test_leads.py               # проверка: python test_leads.py
├── parsers/
│   ├── __init__.py             # модель Lead
│   └── osm.py                  # Overpass API (OpenStreetMap)
├── seen_ids.json               # создаётся автоматически: уже присланные лиды
└── .github/workflows/parser.yml
```

## Как это работает

1. **Overpass** (OpenStreetMap) ищет бизнес нужных категорий в радиусе
   `RADIUS_KM` вокруг точки `CENTER`, у которого **нет** тегов `website`,
   `contact:website`, `url`. Ключ не нужен.
2. В Python отбрасываются точки без названия и без контакта (телефон, Telegram,
   VK, Instagram) — без контакта лид бесполезен.
3. Новые лиды (до `MAX_LEADS` за запуск) уходят одним сообщением, их ID пишутся
   в `seen_ids.json`, чтобы не повторяться.

Данные OSM бесплатны, лицензия ODbL, ключи и регистрации не нужны.

## Настройка

Всё в `config.py`:

| Параметр | Что делает |
|----------|------------|
| `CENTER` | точка поиска `(широта, долгота)`; взять можно в Яндекс.Картах правым кликом → «Что здесь?» |
| `RADIUS_KM` | радиус в километрах (по умолчанию 3 — это ~20–30 минут пешком) |
| `AREA_NAME` | подпись района в сообщении |
| `LEAD_FILTERS` | категории OSM: `amenity`, `shop`, `office`, `leisure` и допустимые значения |
| `MAX_LEADS` | сколько новых лидов в одном сообщении (по умолчанию 10) |
| `MAX_RESULTS` | сколько точек запрашивать у Overpass за раз (по умолчанию 300) |

## Локальный запуск

```bash
cd parser
pip install -r requirements.txt
python test_leads.py      # проверка форматирования, ничего не шлёт
python main.py --dry-run  # показать список лидов
python main.py            # отправить дайджест в Telegram
```

Токен и chat_id лежат в `.env` (в git не попадает); `config.py` подхватывает их
через `os.getenv`, поэтому в Actions работают секреты.

## GitHub Actions

Каждый день в 06:00 UTC (09:00 МСК) + возможность запустить вручную:
Actions → Lead finder → Run workflow.

Секреты (Settings → Secrets and variables → Actions): `TELEGRAM_BOT_TOKEN`,
`CHAT_ID` — те же, что раньше.

## Честные ограничения

- **OSM — не 2ГИС.** Часть бизнесов там не отмечена, у части не заполнен телефон,
  а у некоторых сайт есть, но тег `website` не проставлен. Поэтому перед сообщением
  проверяйте: откройте «Яндекс» по ссылке и убедитесь, что сайта нет. Список — это
  заготовка, а не гарантия.
- Overpass отдаёт не всё: в запросе стоит лимит `MAX_RESULTS` точек. Когда лиды
  закончатся — расширьте категории в `LEAD_FILTERS` или увеличьте `RADIUS_KM`.
- Публичный Overpass периодически перегружен (`502`) — в парсере есть повтор
  с паузой и второй инстанс, но запуск может занять пару минут.
- Не рассылайте всем подряд одно и то же сообщение: это спам и плохая репутация.
  Пишите по делу — «сделал макет для вашего кафе, посмотрите».
